## 📌 Проекты

### 📊 Booking Application — сервис бронирования отелей
[![GitHub](https://img.shields.io/badge/GitHub-Repository-blue?logo=github)](https://github.com/Fakerovi4i/Fast_API_Booking)
[![Swagger](https://img.shields.io/badge/Swagger-Docs-85EA2D?logo=swagger&logoColor=black)](https://booking-application-l2dd.onrender.com/docs)

Full-stack веб-приложение на FastAPI с асинхронной архитектурой, админ-панелью и продвинутыми возможностями.

- **Что сделано:**
  - REST API на FastAPI (асинхронность, JWT-аутентификация, HttpOnly cookies)
  - Схема данных в PostgreSQL, миграции через Alembic
  - Кеширование (Redis) и фоновые задачи (Celery + Flower)
  - Админ-панель (SQLAdmin), импорт из CSV
  - Покрытие интеграционными тестами (pytest + httpx), мониторинг ошибок (Sentry)
  - Упаковано в Docker, задеплоено на Render

### 🤖 Корпоративный ассистент ([@AleonushkaBot](https://t.me/AleonushkaBot))
- **Стек:** aiogram 2, SQLite, APScheduler, Mistral AI, aiohttp, logging
- **Что сделано:**  
  - Админ-панель (задачи с фото, рассылки, бан/разбан, управление админами)  
  - FSM для многошаговых форм  
  - Контекстный ИИ-чат (Mistral AI, история до 20 сообщений)  
  - Планировщик напоминаний (приход/уход, отчёты, контроль)  
  - Полное логирование, обработка ошибок, деплой с healthcheck

### 🎬 Бот для поиска фильмов ([@final_Kino_bot](https://t.me/final_Kino_bot))
- **Стек:** telebot, requests, FSM, динамические клавиатуры, пагинация
- **Что сделано:**  
  - Поиск по названию и сложные фильтры (жанры, страны, рейтинг, год)  
  - Множественный выбор с галочками  
  - Пагинация результатов (5 на страницу)  
  - История поиска пользователя
